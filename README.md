# AI Search Visibility Checklist

A practical, vendor-neutral framework for evaluating whether a brand and its content are discoverable, understandable, authoritative and citation-ready across AI-powered search and answer experiences.

**Maintained by [Touchstone Infotech](https://www.touchstoneinfotech.com/)**

> AI visibility is not controlled by a single ranking factor or guaranteed optimization technique. This checklist focuses on durable fundamentals: accessibility, entity clarity, useful content, evidence, authority, structured information and measurement.

## Recommended workflow

**Discover → Benchmark → Audit → Improve → Validate → Monitor**

Start with a defined set of commercially meaningful questions your audience asks. Benchmark how your brand and competitors appear, audit the underlying signals, improve weak areas, and then repeat the same prompt set over time. AI outputs can vary, so avoid drawing conclusions from a single response.

## Scoring

For each applicable check, use:

- **2** — Pass
- **1** — Needs improvement
- **0** — Fail
- **N/A** — Not applicable

| Score | Interpretation |
|---|---|
| 90–100% | Strong foundation |
| 75–89% | Good, with opportunities |
| 50–74% | Significant improvement needed |
| Below 50% | Weak AI-search visibility foundation |

A score is a prioritization aid, not a guarantee of inclusion or citation by an AI system.

## What not to assume

- There is no universal method that guarantees a ChatGPT, Gemini, Perplexity or AI Overview citation.
- Traditional SEO remains important because accessible, indexable and understandable web content is a foundational discovery layer.
- `llms.txt` and similar emerging conventions should not be treated as substitutes for crawlability, indexing, structured content or authority.
- Schema markup can improve machine understanding but does not guarantee AI citations.
- Repeating keywords or writing mechanically for LLMs is not a substitute for useful, original information.
