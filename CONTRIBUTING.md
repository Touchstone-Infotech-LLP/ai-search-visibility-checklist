# Contributing

Thank you for helping improve the AI Search Visibility Checklist.

The goal of this repository is to maintain a practical, evidence-oriented and vendor-neutral framework as AI-powered search evolves.

## We welcome

- corrections to outdated recommendations,
- new checks supported by reliable evidence,
- links to authoritative first-party documentation,
- clearer explanations,
- useful measurement approaches,
- corrections to broken links or formatting.

## Contribution principles

Contributions should be:

1. actionable,
2. evidence-oriented,
3. vendor-neutral where practical,
4. clear about uncertainty,
5. free from guaranteed-ranking or guaranteed-citation claims.

Please avoid promotional links, fabricated AI ranking factors, keyword stuffing, duplicate checks and unsupported claims about how proprietary AI systems rank or cite sources.

## How to contribute

Open an Issue for discussion or submit a focused Pull Request explaining what you changed and why. For claims about a platform's crawling, indexing or content-use behavior, link to current first-party documentation when available.
